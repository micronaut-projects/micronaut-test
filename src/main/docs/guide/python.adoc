Micronaut applications can also be written in Python (see the https://docs.micronaut.io/latest/guide/#python[Micronaut Framework documentation]), and so can their tests. A Python test class is compiled by `micronaut-inject-python` into a regular JUnit 5 test class, so it uses the JUnit 5 `@MicronautTest` extension described in the <<junit5,previous chapter>>: everything that is a property of the extension (application context per test class, transactions, `@Property`, `@Requires`, parallel execution, ...) behaves the same way, while the tests themselves are written in Python.

This chapter walks through the JUnit 5 examples again, in Python.
