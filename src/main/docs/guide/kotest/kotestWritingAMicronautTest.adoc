snippet::io.micronaut.test.kotest5.MathService[project="test-kotest5", language="kotlin", title="The MathService Interface"]

And a simple implementation that computes the value times 4 and is defined as a Micronaut bean:

snippet::io.micronaut.test.kotest5.MathServiceImpl[project="test-kotest5", language="kotlin", title="The MathService implementation"]

You can define the following test to test the implementation:

snippet::io.micronaut.test.kotest5.MathServiceTest[project="test-kotest5", language="kotlin", title="The MathService specification"]

<1> The test is declared as Micronaut test with `@MicronautTest`
<2> The constructor is used to inject the bean
<3> The test itself tests the injected bean
